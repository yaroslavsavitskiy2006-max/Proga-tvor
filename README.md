# Proga-tvor

Две учебные работы на Python: клиент блокчейн-сети с Proof-of-Work и реализация функциональных списков на замыканиях.

## Состав

### Блокчейн-клиент — `student_client_task.py`

Классы `Block` и `StudentClient` реализуют SHA-256-хеширование блока, подбор nonce, чтение последнего блока и отправку нового блока на сервер.

Установите зависимость и укажите адрес доступного учебного сервера:

```bash
python -m pip install requests
python student_client_task.py --surname "Иванов" --group "КИС-01-22" --server "http://127.0.0.1:5000"
```

Клиент ожидает совместимый сервер с конечными точками `/last_block`, `/add_block` и `/chain`. Сервер в этот репозиторий не входит. Не используйте чужой или недоверенный сервер.

### Функциональные списки — `fvp_implementation.py`

Скрипт содержит операции над списками, представленными замыканиями: `pair`, `head`, `tail`, `foldl`, `foldr`, `list_map`, `list_filter` и другие.

```bash
python fvp_implementation.py
```

Для этой работы достаточно Python 3 и стандартной библиотеки.
